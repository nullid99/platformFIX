# Обсуждения

## Сценарий

Ученик открывает обсуждение из урока. Форма передаёт контекст модуля, урока и, если есть, задания в `POST /api/discussions`. Тема создаётся вместе с первым сообщением одной транзакцией PostgreSQL. Вложения сначала загружаются через защищённый файловый API, а в обсуждении хранится только связь с `StoredFile`; внешняя ссылка сохраняется как `sourceUrl`.

Куратор открывает раздел «Обсуждения». `GET /api/discussions/manage` возвращает только темы владельца или назначенных ему учеников. Ответ куратора создаётся через `POST /api/discussions/:threadId/messages`, меняет статус темы на `ANSWERED` и остаётся в истории после перезагрузки.

## Безопасность

- Студент видит только собственные темы.
- Куратор видит темы назначенных учеников; владелец потока видит все темы.
- Каждый файл проверяется по владельцу и статусу `UPLOADED`.
- Максимум: 5 вложений, 10 МБ на файл, ограниченный список MIME-типов.
- Доступ к медиа проверяется сервером, URL файла не является публичным разрешением.

## Миграция

Сущности `DiscussionThread`, `DiscussionMessage` и `DiscussionAttachment` добавлены миграцией `20260806102347_add_discussions`. Для staging/production применять обычный `npx prisma migrate deploy`.

Пока автоматическая привязка куратора выполняется по назначению ученика в потоке. Отдельный справочник выбора конкретного куратора и email-уведомления подключаются следующим этапом.
