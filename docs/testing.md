# Тестирование

## Уровни

### Unit

Проверяют чистые бизнес-правила без сети и базы:

- переходы статусов ДЗ;
- расчёт прогресса;
- правила сроков и доступа;
- роли и разрешения;
- ограничения повторных попыток.

### Integration

Проверяют API, PostgreSQL, миграции и транзакции:

- создание зачисления;
- отправку и проверку ДЗ;
- отзыв доступа;
- фильтрацию данных по потоку;
- обработку повторного webhook-а.

### Contract

Проверяют форматы интеграций:

- Discord;
- Vimeo;
- email/webhook providers.

### E2E

Playwright проверяет реальные сценарии пользователя:

- вход ученика;
- просмотр доступного урока;
- запрет чужого урока или ДЗ;
- отправка ДЗ с файлом и видео;
- проверка куратором;
- доработка и повторная отправка;
- просмотр видеоразбора;
- отзыв и восстановление доступа.

## Требования к исправлению

Каждый исправленный баг должен иметь тест, который сначала воспроизводит проблему. Тесты не должны зависеть от реальных аккаунтов, production-сервисов или случайного порядка выполнения.

## Проверки перед merge

```text
format
lint
typecheck
unit tests
integration tests
E2E smoke tests
```

При изменении авторизации, доступа, файлов, видео или интеграций обязательны отрицательные тесты.
