# База данных

## Локальная разработка

PostgreSQL используется как основная база проекта. Секрет подключения хранится только в локальном `.env` или в менеджере секретов, а не в репозитории.

Пример переменной находится в `.env.example`:

```text
DATABASE_URL=postgresql://fix_app:<local-password>@localhost:5432/fix_platform?schema=public
```

После создания локального пользователя и базы применяются миграции:

```powershell
$env:DATABASE_URL="postgresql://fix_app:<local-password>@localhost:5432/fix_platform?schema=public"
npx prisma migrate deploy
npx prisma generate
```

Для обычной разработки с изменением схемы используется `prisma migrate dev`. В тестовой и production-среде применяется только `prisma migrate deploy`.

## Auth-модель

- `User` хранит роль и состояние аккаунта. Email необязателен, потому что основной вход passwordless через Discord.
- `ExternalIdentity` связывает пользователя с Discord по неизменяемому provider subject.
- `Invitation` хранит только хеш одноразового токена, срок действия и привязку к identity/практикуму.
- `Session` хранит хеш сессии, защищённый ключ устройства, признаки устройства и ограниченные данные риска.
- `LoginEvent` хранит результат попытки входа, источник и технические признаки для расследования.
- `AuditLog` хранит действия над доступом, учебными материалами и отправками.

Лимит в два устройства проверяется в серверном auth service внутри транзакции: при третьем входе отзывается самая старая активная сессия. IP используется как сигнал риска, а не как единственный идентификатор устройства.

## Миграции и перенос

`ScheduleEvent` хранит события календаря в PostgreSQL. `MediaAsset.scheduleEventId` связывает опубликованную Vimeo-запись с конкретным событием; это отдельная связь от `lessonId`, поэтому запись не заменяет предыдущие записи и остаётся доступной после завершения встречи.

Начальная миграция находится в `prisma/migrations/20260724120000_init`. При деплое на Hetzner сначала создаётся пустая PostgreSQL-база, затем выполняется `prisma migrate deploy`. Данные из локальной среды переносятся отдельно через согласованный дамп, без копирования секретов и локальных сессионных токенов.
